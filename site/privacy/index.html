我们收集什么

账户信息：你登录用的邮箱或 Google 账号，由 Clerk 保存，我们按需读取。我们自己保存账户编号、我们给账户和 cx 的电脑分配的内部编号、Clerk 给你的登录账户编号、你的邀请码，以及注册的时间。

你的内容：对话记录、你上传的文件，以及 cx 为你生成的文件。

你接入的账户和密钥：你自己的模型 API 密钥和数据源凭据，加密保存，只在调用时使用，界面上不再显示。

用量和付款：每一笔扣费和充值的金额、时间和用途；每次调用数据源的记录，包括查询的内容和参数、每一项的结果、数据源返回的说明，以及用量和费用。银行卡和支付宝信息由 Stripe 处理，我们不保存卡号；为防止重复领取邀请奖励，我们保存付款方式的一个不可还原的摘要。

我们怎么用

只用来提供和改进 ComChatX：运行 cx 和 cx 的电脑、调用你选的模型和数据源、计费、防止滥用，以及回复你的来信。

我们不做的事：我们不出售你的个人信息，不用你的内容投放广告。ComChatX 不用你的数据训练模型；模型供应方按它们各自的条款处理。

谁会处理你的数据

为提供服务，下面这些服务商会处理部分数据：Clerk（登录）、Stripe（付款）、Fly.io（运行 cx 的电脑和平台，位于新加坡）、Cloudflare（存储你的文件和对话记录，位于亚太地区）、Supabase（数据库，位于新加坡）。

模型和数据源：你在对话中让 cx 调用模型时，相关内容会发送给该模型的供应方（经 OpenRouter 或你自己的密钥）；调用数据源时，查询会发送给该数据源，例如 Keepa。

保存多久

保存期限：账户存在期间，你的内容一直保存。

删除文件：你可以在对话里让 cx 删除文件；删除的文件不能恢复。

删除账户

怎么删除：在应用的设置里点“删除账户”并确认即可。

删除什么：删除后账户立即停用，我们会取消订阅，销毁 cx 的电脑和它的磁盘，删除你的文件、对话记录、接入的密钥和数据源数据，最后删除你的登录账户。你购买过的数据副本平台保留一份。存储里的删除是立即且不可恢复的。

为了记账和防止滥用，下面这些会保留：每一笔扣费和充值的记录；每次调用数据源的记录（见上文“用量和付款”）；账户编号、内部编号、登录账户编号、邀请码，以及注册和删除的时间；付款方式的摘要。数据库备份保留 7 天，到期后自动删除。

Cookie

必需的 cookie：应用 comchatx.com 只用登录和邀请所必需的 cookie。本网站不使用 cookie，不做跟踪。

你的权利

怎么提出：你可以写信到 support@comchatx.com，要求查看、更正或删除你的个人信息，我们会在核实身份后处理。

政策的修改

更新和通知：我们修改本政策时，会更新本页和生效日期；重要变化会提前在应用里或通过邮件告诉你。
